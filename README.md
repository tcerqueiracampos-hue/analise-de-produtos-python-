# 🛒 Análise de Produtos

Projeto desenvolvido em Python para praticar conceitos de programação e análise de dados utilizando uma lista de dicionários com informações de produtos.

## 🐍 Conceitos utilizados

* Listas
* Dicionários
* Lista de dicionários
* Estruturas `for` e `if`
* Funções
* `return`
* `len()`
* `sum()`
* Compreensão de dicionários
* Generator expressions
* Contadores
* F-strings
* Formatação de valores

## 📊 O projeto analisa

* Quantidade de produtos acima de R$ 500
* Total dos preços dos produtos
* Média geral dos preços
* Produto mais caro
* Produto mais barato
* Quantidade de produtos por categoria
* Soma dos preços por categoria
* Média dos preços por categoria
* Categoria com maior média de preço
* Produtos com preço acima da média geral

## 🎯 Objetivo

Praticar Python utilizando dados estruturados e desenvolver a lógica necessária para realizar análises sobre diferentes conjuntos de informações.

Este projeto faz parte da minha evolução nos estudos de **Python para Dados**.
